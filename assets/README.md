# Template assets go here

This folder holds the files the launch page links to. The template ships
with the paths already wired into `config.js` — drop your real files in
using the same names (or change the paths in `config.js`, which is the
only file you should edit anyway).

Suggested layout:

```
The-Massive-AI-Manual-sample.pdf     sample chapter (sample.downloadFile)
press/
  cover-pack.zip                     mediaKit.coverImages
  author-photos.zip                  mediaKit.authorPhoto
  press-release.pdf                  mediaKit.pressRelease
  author-bio.docx                    mediaKit.authorBio
```

Until a file exists, its media-kit row shows "coming soon" instead of a
broken download link.
